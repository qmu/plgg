# TCP/IP の4層
# 見えるはずのこと: Web と名前解決の経路を上からたどると、どちらも IP に合流し、リンク層で別の回線に分かれます。
layout layered down
axis 層 アプリケーション トランスポート インターネット リンク
node HTTP 層=アプリケーション
node TLS 層=アプリケーション
node DNS 層=アプリケーション
node TCP 層=トランスポート
node UDP 層=トランスポート
node IP 層=インターネット
node ICMP 層=インターネット
node Ethernet 層=リンク
node Wi-Fi 層=リンク
HTTP -> TLS
TLS -> TCP
DNS -> UDP
DNS -> TCP
TCP -> IP
UDP -> IP
ICMP -> IP
IP -> Ethernet
IP -> Wi-Fi
