# plgg-flow

3D 座標を持つ有向グラフを plgg-view の SVG として表示する。初期カメラは正面の平行投影。Shift を押して背景をドラッグすると正面から連続して視点が回り、傾きに応じて遠近感が強くなる。「正面に戻す」で同じカメラが正面まで戻る。背景の通常ドラッグまたは中ボタンドラッグでパンできる。タッチでは背景の1本指ドラッグでパンする。2本指を同じ方向へ動かすと回転し、間隔を変えるとズームする。グループ作成、自動整理、ネスト、図面移行などの200機能を、操作単位で[機能台帳](./CAPABILITIES.md)にまとめている。

| 標準的な機能群 | 初版の範囲 |
| --- | --- |
| ノードの表示・編集 | ID、ラベル、3D 座標、追加、単一選択・複数選択、移動、削除、ラベル描画の差し替え |
| エッジとハンドル | 有向接続、曲線、ポート間のドラッグまたはタップで接続、重複・自己接続の抑止、個別削除 |
| ビューポート | パン、カーソル中心ズーム、全体表示、自由回転、平面復帰 |
| カスタム表示 | ノードラベルに plgg-view の SVG 要素を渡せる |
| 接続規則 | 循環の検出、最大出力数、カスタム検証関数 |
| 関係の編集 | エッジ分割、中間ノードのバイパス、親子の連動移動 |
| エッジの表現 | 曲線・直線・直角経路、ラベル、アニメーション |
| 編集器の組み立て例 | 吸着、幅変更、分岐の開閉、階層配置、ミニマップ、接続先切替 |

| 端末保存と共有 | IndexedDB の版付き保存・下書き自動保存、画像・CSV・Graphviz DOT・読み取り専用 HTML の書き出し |

## 構成

plgg-board は plgg だけに依存する。DOM 型を含まない座標、カメラ、投影、逆回転、深度順描画、線描画コールバックを提供する。ブラウザでは plgg-flow がこれらを plgg-view の svgViewport に接続する。他の描画先は投影済み座標または drawWireframe の線分を受け取って描画できる。

createFlow に nodes と edges を渡し、flowView が返す Html を sandbox に組み込む。イベントから得た Change を現在の Flow に適用する。各ノードの ID は一意、エッジの source と target はノード ID を参照する。

## 任意に読み込めるモジュール

| import パス | 操作 |
| --- | --- |
| `plgg-flow/metadata` | アプリ固有の JSON 設定の検証と部分一致判定 |
| `plgg-flow/spatial` | 3D の距離・角度寸法、軸と深度の配色、断面表示、選択点を中心にした回転、ワールド座標の範囲計測 |
| `plgg-flow/revisions` | 基準版との差分、逆パッチ、競合を検出するアトミックな差分適用、3方向マージ |
| `plgg-flow/connections` | 名前付きポートの追加・改名・削除、エッジ ID による個別編集、接続条件を検査した再接続 |
| `plgg-flow/hierarchy` | 複数の兄弟を囲む、親の付け替え、ネストの解除、子孫を含む移動・削除、グループ収納と境界を越える接続の表示 |
| `plgg-flow/layout` | 循環を含む依存関係の階層配置、グループ単位の配置、放射状配置、Z 軸への階層の割り当て、重なりの解消 |
| `plgg-flow/topology` | 入出力の索引、強連結成分、依存の深さ、最短有向経路 |
| `plgg-flow/edits` | 内部の接続と親子関係を保つ部分グラフの取り出し・貼り付け、ノード統合、接続反転、推移簡約、整列、等間隔配置、鏡像・回転・拡縮、位置固定、枝の非表示、一括ラベル置換、参照を保つ ID 変更 |
| `plgg-flow/interchange` | カメラを含む版付き JSON の保存・読込、参照整合性の検査、React Flow JSON の移行 |

「グループとネスト」で Shift＋クリックすると複数のカードを選べる。Alt＋背景ドラッグでは画面上の矩形で範囲を選べる。地面の表側は薄緑、裏側は土色、空間は青。表示名は格子面とカメラの位置関係から決まる。

各サンプルの「編集ツール」から、部分グラフの編集、検索、最短経路の強調、ファイルに保存できる JSON テキストの入出力を試せる。個別モジュールは DOM を要求しない。入力の構文・型・参照が無効な場合、ローダーはエラーを返し、開いている図面を保持する。

React Flow の移行では、親基準の座標をワールド座標へ展開し、文字列ラベル、接続、ビューポート、標準経路、グループ、非表示・固定状態を読み込む。エッジ ID と名前付きハンドルは移行後も保持する。カスタムの型名と JSON の data、ノード寸法、相対原点を保持する。カスタムコンポーネントの表示は ViewRegistry に登録できる。任意の CSS と React コンポーネントの実装は移植が必要。読み込み時に該当する項目を表示する。[React Flow のサブフロー仕様](https://reactflow.dev/learn/layouting/sub-flows)

## 20 個の操作例

初期表示の「立体交差」は正面から始まる。格子と各ノードの接地点も世界座標に置き、ノードと曲線の各区間を奥から描く。回転中もノードのラベルはカメラを向く。

ギャラリーは立体交差、エッジへの挿入、接続先変更、循環防止、出力制限、中間ノード削除、グリッド吸着、リサイズ、表示名編集、経路切替、アニメーション、条件ラベル、折りたたみ、親子移動、自動配置、コピー・貼り付け、Undo / Redo、保存・復元、計算ノード、ミニマップを個別に試せる。

リポジトリ直下で次を実行し、localhost の 51826 番を開く。サンプルを切り替えても、ページを開いている間はそれぞれの編集状態を保持する。

```sh
sh scripts/build.sh
python3 -m http.server 51826 --bind 127.0.0.1 --directory packages/plgg-flow-example/dist
```

[機能台帳](./CAPABILITIES.md) に、付随する操作を一つにまとめた機能単位と実装モジュールを記載している。メインの編集モデルは `plgg-flow/model`、端末保存は `plgg-flow/storage`、注釈は `plgg-flow/annotations`、障害物回避は `plgg-flow/routing` から個別に読み込める。ノードの data に入った文字列はデータとして扱い、HTML や実行コードには変換しない。
