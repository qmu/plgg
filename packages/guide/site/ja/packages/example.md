# example — To-Do アプリを動かす

[入門](/getting-started/)の手順でワークスペースをビルドし、`packages/example` で `npm run serve` を実行します。表示された URL を開き、項目の追加、完了、絞り込みを試してください。検索条件を変えると URL も変わるので、ブラウザーで戻ったときの表示を確かめられます。

停止して `npm run serve:ssr` を実行すると、同じ `view` でサーバー側から HTML を返す例を試せます。

## 描画と状態を追う

`src/app.ts` の `init`、`update`、`view` を順に読むと、入力中の文字列と登録済みのタスクをどこで分けるかがわかります。`src/app.spec.ts` はメッセージを直接渡す試験と、DOM に入力イベントを送る試験を持っています。SSR は同じ `view` を文字列化し、起動したクライアントは最初の描画でルートを作り直します。タスクの保存先はモデルで、DB への永続化はありません。
