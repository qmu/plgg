# plggmatic-example — Run the reference screens

Demo 1 brings the [component catalog](https://plggmatic.qmu.co.jp/en/) into a working screen. `src/demo1-main.ts` applies the theme, chooses an appearance from storage and device preferences, then mounts the program. Read the declaration for screen structure and the browser entry for startup behavior. Use `npm run dev` to try changes and `npm run build` to produce the exhibit.
