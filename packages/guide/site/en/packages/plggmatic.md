# plggmatic — Choose components for a view

Supplies shared controls and horizontal layouts for plgg-view. Controls emit messages and the application updates its model. New shared parts and their styles belong here so consuming sites can reuse them. Try the controls in the [component catalog](https://plggmatic.qmu.co.jp/).

See [package boundaries](/design/family/) for dependency direction and [Build a bookshelf](/tutorial/) for an end-to-end application.
