# plggpress — Publish a Markdown site

Generates static pages from Markdown and site configuration. plggmatic supplies the frame and plgg-md renders the body. plgg-cms serves applications where editors sign in to change published content. [Build a first site](https://plggpress.qmu.co.jp/start/).

See [package boundaries](/design/family/) for dependency direction and [Build a bookshelf](/tutorial/) for an end-to-end application.
