# チームと、リリースの工程

```plgg-flow fill dsl tools=hidden
layout rooms
axis 工程 設計 実装 検査 公開
axis 担当 画面 業務 基盤
view x=工程 y=担当
node 画面設計 工程=設計 担当=画面
node API設計 工程=設計 担当=業務
node 構成設計 工程=設計 担当=基盤
node 画面実装 工程=実装 担当=画面
node API実装 工程=実装 担当=業務
node 基盤実装 工程=実装 担当=基盤
node 結合検査 工程=検査 担当=基盤
node 受入検査 工程=検査 担当=画面
node 負荷検査 工程=検査 担当=基盤
node 公開 工程=公開 担当=基盤
画面設計 -> 画面実装
API設計 -> API実装
構成設計 -> 基盤実装
画面実装 -> 結合検査
API実装 -> 結合検査
基盤実装 -> 結合検査
結合検査 -> 受入検査
結合検査 -> 負荷検査
受入検査 -> 公開
負荷検査 -> 公開
```
