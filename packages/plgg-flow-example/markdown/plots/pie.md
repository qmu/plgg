# 全体の中の割合を見る

```plgg-flow fill dsl
layout pie
axis 売上
axis 年 2024 2025 2026
node 食品 売上=40,52,61
node 衣料 売上=30,28,24
node 家電 売上=20,34,58
node 雑貨 売上=10,12,13
```

node 1 つが 1 切れです。量をコンマで並べると、並べた数だけ円ができ、2 つ目の軸がそれぞれの円の名前になります。切れは書いた順に、真上から時計回りに並びます。

**円の大きさは合計の大きさ**です（幅ではなく面積で比べます）。だから「家電の割合が増えた」ことと「全体が大きくなった」ことが、同じ絵から読めます。量を 1 つだけ書けば、円は 1 つです。
