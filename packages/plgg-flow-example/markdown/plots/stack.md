# 合計と内訳を積んで見る

```plgg-flow fill dsl
layout stack
axis 売上 higher
axis 月 1月 2月 3月 4月 5月 6月 7月 8月
node 東 売上=22,30,41,48,63,74,86,93
node 西 売上=64,70,66,58,52,47,40,36
node 南 売上=12,26,48,70,58,34,44,60
```

書いた順に下から積みます。いちばん上の線が合計、帯の厚みがそれぞれの内訳です。量の範囲を書かなければ、合計のいちばん高いところまでが自動で目盛りになります。
