# いくつもの条件で形を比べる

```plgg-flow fill dsl
layout radar
axis 速さ 0..10 higher
axis 費用 0..200 lower
axis 品質 0..10 higher
axis 保守しやすさ 0..10 higher
axis 導入の手間 0..10 lower
node 既製品 速さ=8 費用=160 品質=6 保守しやすさ=8 導入の手間=2
node 自作 速さ=6 費用=60 品質=9 保守しやすさ=4 導入の手間=8
node 半自作 速さ=7 費用=100 品質=8 保守しやすさ=7 導入の手間=5
```

軸 1 本が、中心から伸びる 1 本になります。**どの軸も外側が良い側**です。`lower` と書いた軸（低いほど良い）は向きを裏返すので、形が大きい案ほど良く、ある案の形が別の案からはみ出しているところが、その案の勝っているところです。

最初は正面から、形を重ねて見せます。案は書いた順に奥から手前へ離して置いてあるので、⌘（Ctrl）を押しながらドラッグして回すと、1 枚ずつに分かれて見えます。
