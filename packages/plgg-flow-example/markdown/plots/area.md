# 推移を系列ごとに奥へ並べる

```plgg-flow fill dsl
layout area
axis 売上 0..100 higher
axis 月 1月 2月 3月 4月 5月 6月 7月 8月
node 東 売上=22,30,41,48,63,74,86,93
node 西 売上=64,70,66,58,52,47,40,36
node 南 売上=12,26,48,70,58,34,44,60
```

系列は `node` 1 行で書けます。量の属性に値をカンマで並べると、2 本目の軸の順にたどった 1 本の系列になり、書いた順に奥から手前へ並びます。

1 点ずつ書くこともできます（棒グラフと同じ書き方）。その場合は 3 本目の軸で系列を分けます。

```
layout area
axis 売上 0..100 higher
axis 月 1月 2月 3月
axis 地域 東 西
node 東1 月=1月 地域=東 売上=22
node 東2 月=2月 地域=東 売上=30
```
