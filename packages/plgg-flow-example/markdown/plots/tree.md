# 全体が何でできているか

```plgg-flow fill dsl
layout tree
axis 人数
会社 -> 開発
会社 -> 営業
会社 -> 管理
開発 -> 基盤
開発 -> 画面
開発 -> 品質
営業 -> 国内
営業 -> 海外
node 基盤 人数=6
node 画面 人数=14
node 品質 人数=4
node 国内 人数=9
node 海外 人数=5
node 管理 人数=4
```

`A -> B` は「A は B でできている」と読みます。親は子の真上に、**子を合わせた幅**で立ちます。だから 1 段を横に見れば、上の段の内訳がそのまま割合で読めます。

量の軸を書くと、葉（子のない node）はその量の幅になり、親は下の合計になります。名前の下に量と、全体に対する割合が出ます。軸を書かなければ、葉はどれも同じ幅です。

段は下へ行くほど手前に置いてあります。⌘（Ctrl）を押しながらドラッグして回すと、段々になって見えます。
