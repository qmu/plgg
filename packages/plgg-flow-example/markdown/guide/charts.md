# グラフの選び方と構文

各シートの先頭に `layout` を一つ書き、続く `axis` でデータの読み方を決めます。同じ売上でも、地域別の高さを比べるなら棒、月ごとの合計を見るなら積み上げが適しています。表のリンクを開くと、その構文で書いた図を隣の列で試せます。

## 案や数量を比べる

| 配置と実例 | 軸とデータの書き方 |
| --- | --- |
| [`layout plot`](../plots/options.md) | 数値軸を 2 本または 3 本書き、各ノードに各軸の値を書きます。宣言順に x、y、z に割り当てられます。`view x=費用 y=性能` のように順序を指定することもできます。追加の 1 軸に `size` を付けると印の大きさを表せます。 |
| [`layout bars`](../plots/bars.md) | 1 本目が高さを決める量、2 本目が横に並べる分類、任意の 3 本目が奥行きの分類です。一つのノードが 1 本の棒になります。分類の値を列挙すると順序を指定できます。 |
| [`layout radar`](../plots/radar.md) | 3 本以上の数値軸を宣言します。各ノードの値を軸ごとの範囲に合わせ、中心からの距離で表します。`lower` の軸では小さい値ほど外側に来ます。 |
| [`layout pie`](../plots/pie.md) | 1 本目が量の属性で、各ノードに 0 以上の値を書きます。一つのノードが一切れです。`売上=40,52,61` のようなリストは複数の円になり、任意の 2 本目の軸で円に名前を付けられます。切れの角度は割合、円の面積は合計を表します。 |

散布図では `axis 費用 0..200 lower <=150` のように指定します。`0..200` は目盛りの範囲で、省けばデータから決まります。`lower` は小さいほど、`higher` は大きいほど有利な軸です。比較に使うすべての軸で同等以上、かつ少なくとも一つで上回る案があると、劣る案が薄くなります。

`<=150` と `>=50` は端を含む上限と下限です。条件から外れた案は薄くなり、ほかの案を評価する際の比較対象からも外れます。[人数を印の大きさで表す例](../plots/conditions.md)と[効果と手間を比べる例](../plots/quadrant.md)で試してください。

## 順番に沿って変わる量を読む

次の 3 種類は同じデータを使えます。1 本目の軸が量、2 本目が月などの順序です。一つのノードに値をカンマ区切りで書くと、そのノードが一つの系列になります。この形式では軸は 2 本です。横軸の値を省くと 1 から順に番号が付きます。

```text
layout line
axis 売上
axis 月 1月 2月 3月
node 東 売上=22,30,41
node 西 売上=64,70,66
```

- [`layout area`](../plots/area.md) は系列ごとの値を面で結び、系列を奥行きに沿って並べます。
- [`layout line`](../plots/line.md) は同じ平面に線を重ねます。交点の前後で、どちらの値が高いかを読めます。
- [`layout stack`](../plots/stack.md) は系列順に下から積みます。帯の厚さは各系列の量、上端は合計です。範囲を省くと合計が目盛りに収まります。

観測値ごとにノードを作る場合は、3 本目の軸で系列を分けられます。たとえば `axis 地域 東 西` を加え、`node 東1 月=1月 地域=東 売上=22` と書きます。

## 内訳、流れ、時間を読む

| 配置と実例 | 軸とデータの書き方 |
| --- | --- |
| [`layout tree`](../plots/tree.md) | `親 -> 子` で内訳を表します。各子の親は一つまでで、循環は作れません。軸を省くと葉の幅は一定です。量の軸を 1 本指定すると、葉の値の合計が親の幅を決めます。 |
| [`layout sankey`](../plots/sankey.md) | 1 本目の軸が流量の属性です。すべての接続に `売上 -> 粗利 金額=62` のように数値を書きます。量が多いほど帯が太くなります。任意の 2 本目の軸はノードを奥行きに分けます。 |
| [`layout sequence`](../plots/sequence.md) | ノードが参加者、接続がメッセージです。接続を書いた順に上から並び、引用符で囲んだラベルがメッセージ名になります。軸は省略でき、1 本指定すると参加者を奥行きで分けられます。 |
| [`layout timeline`](../plots/timeline.md) | 1 本目の軸が時間です。`axis 週 0..12` の範囲は省略できます。各ノードの `週=2..5` は期間、`週=12` は一点を表します。任意の 2 本目の軸で担当などの区分を奥行きに並べます。 |
