# 配置と視点

図は 900 × 580 の平面の上にあり、`at x y z` の z が奥行きです。

## 操作

| 操作 | 結果 |
| --- | --- |
| 背景をドラッグ | 視点を平行移動 |
| Shift ＋ドラッグ | 視点を回転 |
| Ctrl（⌘）＋スクロール | 拡大・縮小（ただのスクロールはページを送ります） |
| 2 本指 | 回転とピンチズーム |

## 奥行きのある配置

```plgg-flow
node 手前 at -160 0 180
node 中央 at 0 0
node 奥 at 160 0 -180
手前 -> 中央
中央 -> 奥
```

「立体」を押してから回すと、3 つのノードが奥へ並んでいるのが分かります。
