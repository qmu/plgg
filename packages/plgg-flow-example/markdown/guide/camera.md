# 配置と視点

`at x y z` の最初の二つの数は横と縦の位置です。右ほど x が大きく、下ほど y が大きくなります。正面から見て、z が大きいほど手前です。下の図を回して、中央の箱を基準に前後を確かめてください。

```plgg-flow
node 手前 at -160 0 180
node 中央 at 0 0
node 奥 at 160 0 -180
手前 -> 中央
中央 -> 奥
```

| 操作 | 図の変化 |
| --- | --- |
| 背景をドラッグ | 視点が平行移動します。 |
| Shift を押してドラッグ | 範囲内のノードを選べます。 |
| ⌘ または Ctrl を押してドラッグ | 視点が回転します。 |
| ⌘ または Ctrl を押してスクロール | 拡大・縮小します。 |
| タッチ画面で 2 本指を使う | 回転やピンチによる拡大・縮小ができます。 |

[層の図](../samples/layers.md)では同じ分類のノードが同じ板に乗ります。[部屋の図](../samples/rooms.md)では、軸の値を選んで区画に注目できます。
