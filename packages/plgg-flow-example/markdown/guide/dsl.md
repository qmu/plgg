# DSL の構文

1 行に一つ、ノード、接続、または図全体への指示を書きます。空行は無視されます。`#` から行末まではコメントです。空白や `#` を含む名前は二重引用符で囲みます。引用符の中では `\"` と `\\` で引用符とバックスラッシュを表せます。

## ノードを書く

`node ID` で一つのノードを宣言します。ID は図の中で一意です。初期の表示名は ID、位置は原点です。次の指定を同じ行に足せます。

| 指定 | 用途 |
| --- | --- |
| `at x y [z]` | 中心の座標を指定します。z の初期値は 0 です。 |
| `label "表示名"` | 接続に使う ID を保ったまま表示名を変えます。 |
| `width 幅`、`height 高さ` | カードの寸法を指定します。 |
| `group`、`in 親ID`、`collapsed` | グループを作り、子を親に所属させたり、折りたたんだ状態にしたりします。親には図に存在する ID を使います。 |
| `grow x y` | グループの枠を、中身に必要な大きさから横・縦に広げます。 |
| `value 数` | [計算ノード](../samples/compute.md)の入力値を設定します。 |
| `属性=値` | 分類やグラフが読む属性です。複数書けます。空白を含む場合は `"所属=開発 チーム"` のように指定全体を囲みます。 |

```plgg-flow
node Source at -220 -50
node "Long name" at 0 15 label "表示名だけ変える"
node Result at 220 -50 width 150
Source -> "Long name"
"Long name" -> Result
```

## 接続を書く

`A -> B` は A から B への接続です。矢印の前後には空白を入れます。端点にだけ書いた名前もノードになります。矢印を連ねるときは、接続ごとに改行します。

行末に `"ラベル"`、経路の `straight`（直線）、`step`（直角）、`curve`（曲線）のいずれか、流れを示す `animated` を加えられます。`量=60` のように接続にも属性を付けられます。接続上の引用符付きの語はラベルとして読まれます。

```plgg-flow
node Input at -220 0
node Route at 0 0
node Live at 220 -85
node Backup at 220 85
Input -> Route animated
Route -> Live "通常" curve
Route -> Backup "障害時" step
```

## 接続と移動に制限を付ける

`rule acyclic` は循環を作る新しい接続を拒みます。`rule max-outputs 2` は一つのノードから出せる接続を 2 本までにします。二つの規則は併用できます。`snap 32` は移動時の格子間隔を 32 にします。初期値は 16 で、`snap off` または `snap 0` で吸着を解除できます。

```plgg-flow
rule acyclic
snap 32
node Source at -220 -50
node Process at 0 15
node Result at 220 -50
Source -> Process
Process -> Result
```

## 自動で並べる

`layout layered [right|down] [depth]` は接続から段を作ります。既定の right は右へ、down は下へ進みます。depth を加えると段ごとに奥行きが付きます。`at` で位置を書いたノードは自動配置の対象から外れます。[接続だけで並べた図](../samples/layered.md)で試してください。

属性ごとに板を分けるには、layered に `axis 層 画面 処理 保存` を一つ加えます。各ノードには `層=処理` などを書きます。この軸は `view layer=層` でも指定できます。属性による層分けと depth は併用できません。板の上で位置を指定すると x と z は板の内側に収まります。

## 部屋と視点を指定する

`layout rooms` は属性の組み合わせごとに部屋を作ります。`axis 属性 [値…]` で軸を宣言します。列挙した順に値が並び、未記載の値はノードから補われます。軸名は重複できません。役割を省略すると、図に合う軸の割り当てと視点が選ばれます。

```text
layout rooms
axis 層 画面 処理
axis 地域 東京 大阪
view y=層 column=地域 camera=-0.4,-0.3
node 受付 層=画面 地域=東京
node 決済 層=処理 地域=大阪
受付 -> 決済
```

`view` では `x`、`y`、`z` が部屋の方向、`column`、`row` が部屋のまとまりを並べる列と行です。`pin=地域=東京` は地域を東京に固定し、`pin=地域` では先頭の値を使います。役割には宣言済みの属性を割り当てます。`axis x 地域 東京 大阪` の形でも x、y、z の役割を指定できます。属性名自体が x のときは `axis "x" 低 高` と書きます。

`view camera=yaw,pitch` は部屋、属性で分けた層、グラフの初期角度をラジアンで指定します。`mark A B` は注目するノードを示します。特定の接続は `mark "A -> B"` で指定できます。[データの流れ](../subjects/lineage.md)で、印を付けた経路をたどってください。

## 値で位置を決める

この図の横軸は費用、縦軸は性能です。案 B は案 C より安く、性能も高いので、案 C が薄く表示されます。

```plgg-flow
layout plot
axis 費用 0..200 lower
axis 性能 0..100 higher
node 案A 費用=60 性能=70
node 案B 費用=140 性能=90
node 案C 費用=150 性能=60
```

[グラフの選び方と構文](./charts.md)では、数値、分類、順序、時間を `axis` と属性で表す方法を説明します。
