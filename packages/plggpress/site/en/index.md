# The plggpress guide

plggpress turns Markdown into a static documentation site. When a procedure mentions a setting, you can follow the link and read its definition in the next column while keeping your place in the procedure.

Try it here. Open [Reading in columns](/columns/) and follow another link from there. The same gesture works across participating sites. For example, the [plgg guide](https://plgg.qmu.co.jp/) introduces the libraries that power plggpress.

To build your own site, start with [Your first site](/start/). If you already have a set of documents, see how [Markdown files map to URLs](/markdown/) or go straight to [Building and publishing](/operations/).
