# plggpress ガイド

plggpress は、Markdown から静的なドキュメントサイトを作るツールです。手順を読みながら設定項目を調べたいときは、本文のリンクを開いてください。手順を左の列に残したまま、右の列で説明を読めます。

このページで試してみましょう。[列で読む](/columns/)を開き、そこからもう一つリンクをたどってください。別のサイトの資料も同じように開けます。たとえば、plggpress を支えるライブラリは [plgg のガイド](https://plgg.qmu.co.jp/)で紹介しています。

自分のサイトを作るには、[最初のサイト](/start/)でトップページを書きます。すでに原稿がある方は、[Markdown とリンク](/markdown/)でファイルと URL の対応を確認するか、[ビルドと公開](/operations/)へ進んでください。
