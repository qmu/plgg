# 列で読む

まず[ページの書き方](/markdown/)を開きます。このページは左に残り、右に記事が並びます。右の記事からリンクをたどると、そのまた右に列が増えます。左の列に戻って別のリンクを選ぶと、その位置より右側が新しい行き先に入れ替わります。

追加した列の見出しには閉じるボタンがあります。押すと、その列と右側の列が閉じます。開いている列の一覧では、タイトルを選んで目的の列まで移動できます。

## 同じ並びを共有する

アドレスバーの URL をそのままコピーします。最初のページはパスに、その右のページは `c` というクエリーパラメーターに順番に入ります。たとえば `/columns/?c=/markdown/,/sheets/` は 3 ページを並べたアドレスです。英語版では各パスに `/en/` が付きます。再読み込みやブラウザーの「戻る」でも、アドレスに合わせて列が復元されます。

## 狭い画面で読む

列を横にスクロールすると、先ほどのページに戻れます。それぞれの本文は縦にスクロールできます。目次は画面上部のメニューボタンから開けます。別のサイトのページも隣に並べたい場合は、[サイトをつなぐ](/joining/)を参照してください。
