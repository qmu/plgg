# Serve the plggmatic reference exhibit on plgg.qmu.co.jp

## Summary

The plggmatic reference exhibit (demo1) is now served from the guide's own domain at plgg.qmu.co.jp/plggmatic-reference/demo1.html. The guide build nests the built exhibit into its dist, the deploy workflow runs the guide's own build script, and the landing page links to the exhibit with a real link.

## Key Changes

- `packages/guide/nest-exhibit.ts` nests the built exhibit under the guide dist after `plggpress build` (the ordering is load-bearing: plggpress cleans the outDir before writing).
- `deploy-guide.yml` runs `npm run build --prefix packages/guide` instead of an inline `npx plggpress build`, closing the last second-copy of the build topology.
- The landing page's `<https://…>` pseudo-autolinks, which rendered as escaped literal text, became a real on-domain markdown link.

## Changes

### Added

- The plggmatic reference exhibit served at `/plggmatic-reference/` on plgg.qmu.co.jp, nested by the guide build.
