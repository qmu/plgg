# Removed the tracked copy of the generated tsconfig.dts.json etc

## Summary

`packages/plgg-ir-manifest/tsconfig.dts.json` was under version control even though plgg-bundle writes it and removes it on every declaration build. Untracking it, and ignoring the filename repository-wide, stops a library build from leaving a deleted tracked file behind.

## Key Changes

- Removed the tracked copy of the generated `tsconfig.dts.json` from `packages/plgg-ir-manifest` — the only one among 37 library target packages
- Added `**/tsconfig.dts.json` to `.gitignore` beside plgg-bundle's other transient artifacts
- Spelled the pattern in full rather than as a `tsconfig*` wildcard, so `tsconfig.json` and `tsconfig.build.json` stay tracked

## Changes

### Changed

- Untracked the generated `tsconfig.dts.json` and ignored it repository-wide, so a build no longer dirties the worktree and the claim teardown and Workspace Guards stop reporting phantom uncommitted work
