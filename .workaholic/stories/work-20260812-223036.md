## 1. Overview

Adopted `@types/node` 26.2.0 across all 29 workspace manifests and the root lockfile, taking dependabot PR #113's change through the repository's own gates. The upgrade turned out to be a true no-op at the type level: zero new type errors across the whole 29-package type graph, no escape hatches added, and `npm audit` stays at 0.

**Highlights:**

1. 29 manifests moved from `^25.6.0` to `^26.2.0`, with the root lockfile resolving 26.2.0
2. The whole-repo typecheck is clean — the five packages that failed initially were the fresh-worktree stale-dist gotcha, not the upgrade
3. This is deliberately sequenced before the `typescript-7-migration` mission, so the types baseline is settled before the compiler changes

## 2. Motivation

This was the first dependabot update PR to arrive against the workspaces root after `.github/dependabot.yml` was repointed from `/packages/*` to `/` — proof the repointed config works. The last TypeScript major (commit `750b8b61`, 2026-05-13) took TS 5→6 and `@types/node` 24→25 in one commit, and the one recorded cost was their interaction. Landing the types major alone, first, keeps the upcoming TS7 work cleanly attributable.
